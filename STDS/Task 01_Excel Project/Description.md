📊 Adventure Works Sales Analysis – Excel Dashboard
This project is an interactive Excel dashboard built to analyze the sales performance of Adventure Works across multiple dimensions such as time, products, customers, pricing, geography, and profitability.
The dashboard is designed to help stakeholders quickly understand key business insights, identify profit drivers, and support data-driven decision making using visual analytics.

🎯 Project Objective
The goal of this project is to demonstrate how Excel can be used as a powerful data analytics and visualization tool, capable of delivering insights similar to BI tools, while remaining simple and accessible.
